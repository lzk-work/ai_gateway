# 1688关键词提取

这是通用 `text_to_text` 引擎的一个任务定义。Excel 表头直接对应 `prompt.txt` 中的 `{{ 占位符 }}`。每行生成一个完整提示词，并作为单条 `user` 消息独立调用兔子文本 API。

默认输入：`input/source.xlsx`。批次状态与输出：`batches/<批次ID>/`。

该任务不预设 SKU 唯一性、必填业务字段或控制列。实际需要替换的表头完全由用户手动放入 `prompt.txt` 的占位符决定。

`prompt.txt` 当前逐字保存用户提供的原始提示词，框架不会自动追加、删减或改写内容。正式运行前由用户在需要的位置手动加入 `{{ Excel表头 }}` 占位符；没有占位符时模板预检必须失败，禁止调用 API。
